# ADR-0001: Managed Docs Protocol canary qualification

## Context

The disposable repository must prove the qualified Cohort through the same
commands and protected reusable workflow used by organization consumers.

## Decision

Adopt `docs-2026-08-17-rc3` and retain this generated ADR as authoring evidence.

## Consequences

The canary can be reset or archived without affecting a production project.
